# 🌱 PlantCare

**App móvil para recordatorios de riego de plantas**

---

## Sobre el Proyecto
Aplicación Android desarrollada en Java que te ayuda a gestionar el cuidado de tus plantas mediante recordatorios.

### Características
- Registro de plantas con información detallada
- Recordatorios personalizados de riego
- Toma de fotos integrada con cámara
- Interfaz moderna con Material Design 3

## Tecnologías
- **Lenguaje:** Java
- **Arquitectura:** MVVM + Repository
- **Base de datos:** Room
- **UI:** Material Design 3
